# لوحة تحكم المدير (Admin Web Dashboard)

مشروع React + Vite منفصل تمامًا عن تطبيق الكاشير (Electron)، ويتصل بنفس
مشروع Supabase ونفس الجداول الموجودة بالفعل (بدون أي جداول أو منطق مكرر).

## الصفحات
- **نظرة عامة**: مبيعات اليوم/الشهر، الإيرادات، الربح، المصروفات، صافي الربح، عدد الفواتير.
- **الكاشير**: شاشة بيع كاملة من الموبايل — سلة، بحث/باركود، إتمام بيع، اختيار نوع الطلب
  (تيك أواي / صالة برقم طاولة / توصيل بعنوان ورسوم)، ربط عميل تلقائيًا من رقم الهاتف،
  إنشاء فاتورة، وطباعة الفاتورة عبر متصفح الموبايل.
- **تقارير المبيعات**: يومي/شهري/فترة مخصصة + طرق الدفع + الأكثر مبيعاً + قائمة الفواتير.
- **العملاء**: إضافة/تعديل/حذف، بحث، سجل مشتريات لكل عميل، إجمالي المشتريات، آخر زيارة، واتساب.
- **المنتجات**: إضافة/تعديل/حذف منتج، حالة المخزون (منخفض/نافد)، الأكثر مبيعاً هذا الشهر.
- **المخزون**: عرض الكمية الحالية، تعديل الكمية (إضافة/سحب/تسوية جرد)، قيمة المخزون (منتجات + مواد خام) والحد الأقصى القابل للتصنيع، سجل الحركات، ونقل مخزون بين الفروع مع سجل كامل.
- **المواد الخام**: إدارة المواد الخام (وحدة الاستهلاك، حد التنبيه)، تسجيل الشراء مع تحويل الوحدة تلقائيًا وحساب متوسط التكلفة المرجّح (WAC)، وتعديل الكمية يدويًا (إضافة/سحب/تسوية/هالك). من صفحة "المنتجات" يمكن ربط كل منتج بوصفة (BOM) من المواد الخام، فتُحسب تكلفة المنتج تلقائيًا من تكلفة مكوّناته، وتُخصم كمياتها من المخزون تلقائيًا عند البيع (مع منع البيع لو الكمية غير كافية).
- **الحسابات**: إضافة إيراد/مصروف يدوي وحذفه، إيرادات/تكلفة/ربح المبيعات، صافي الربح أو الخسارة.
- **مقارنة الفروع**: جدول ورسم بياني يقارن كل فرع (المبيعات، الإيرادات، الربح،
  المصروفات، عدد الفواتير، عدد العملاء، قيمة المخزون) لأي فترة زمنية.
- **المستخدمون**: عرض كل المستخدمين، تغيير الدور (مدير/مشرف/كاشير)، تخصيص الفرع، تفعيل/إيقاف الحساب.
- **آخر الأنشطة**: تغذية مباشرة (Realtime) لأحدث الفواتير وحركات المخزون والحركات المالية،
  مبنية من البيانات الفعلية الموجودة أصلاً (لا يوجد جدول أجهزة/فروع منفصل في المخطط الحالي).

هذه اللوحة أصبحت الآن بديلاً كاملاً لتطبيق الكاشير (سطح المكتب) يعمل من أي متصفح موبايل،
ويستخدم نفس قاعدة البيانات ونفس منطق الفرع/الصلاحيات تمامًا.

## فلترة الفروع
قائمة اختيار أعلى كل صفحة تسمح بعرض "كل الفروع" مجمّعة أو التصفية لفرع واحد محدد؛
كل الصفحات (عدا "مقارنة الفروع" التي تعرض كل الفروع دائمًا جنبًا إلى جنب) تحترم هذا الاختيار.

## تسجيل الدخول
- الدخول متاح فقط للحسابات التي دورها `admin` في جدول `profiles`.
- لو حساب غير مدير حاول الدخول، هيتم تسجيل خروجه تلقائيًا مع رسالة توضيحية.

## التشغيل
```bash
npm install
npm run dev
```
يفتح على `http://localhost:5174`.

## البناء للنشر
```bash
npm run build
```
الناتج في `dist/` — أي استضافة ستاتيك عادية تكفي (Vercel, Netlify, Cloudflare Pages, أو حتى استضافة عادية عبر Nginx).

## الاتصال بقاعدة البيانات
بيانات الاتصال بـ Supabase موجودة في `src/lib/supabase.js` (نفس المشروع المستخدم
في تطبيق الكاشير). لا حاجة لأي إعداد إضافي في القاعدة — اللوحة تقرأ فقط من
الجداول الموجودة: `profiles`, `products`, `categories`, `sales`, `sale_items`,
`customers`, `transactions`, `inventory_movements`, `raw_materials`, `product_recipe_items`.

> صفحة "المواد الخام" ووصفات المنتجات (BOM) تتطلب تشغيل `sql/migration_v11.sql`
> و`sql/migration_v12.sql` على نفس مشروع Supabase (نفس الملفات المستخدمة في تطبيق
> الكاشير) — إذا كانت مُطبّقة بالفعل هناك فلا حاجة لأي إعداد إضافي هنا لأن اللوحة
> تتصل بنفس القاعدة. نوع الطلب (تيك أواي/صالة/توصيل) في شاشة الكاشير يعتمد على
> أعمدة `order_type`/`table_number`/`delivery_address`/`delivery_fee` على جدول
> `sales` (`sql/migration_v9.sql`) — بدون إضافة شاشة عرض المطبخ نفسها لهذه اللوحة.

## Realtime
كل صفحة تشترك في تحديثات Supabase Realtime على الجداول ذات الصلة، فأي عملية بيع
أو تعديل من أي جهاز (تطبيق الكاشير أو جهاز آخر) تنعكس تلقائيًا هنا خلال أقل من ثانية.
